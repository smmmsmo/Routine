# Routine

A general-purpose repository for personal routines, structured learning plans, notes, progress tracking, and long-term projects.

## Repository boundary

This repository is the **schedule and progress layer**. It says what to study,
when to study it, and how to track progress; it does not replace the detailed
learning repositories.

- [`MooLearning/python`](https://github.com/MooLearning/python) is the canonical
  detailed Python, DSA, data-science, and introductory AI/ML curriculum.
- [`MooLearning/cpp`](https://github.com/MooLearning/cpp) is the canonical
  detailed C++ curriculum.
- [MAANG engineering roadmap](maang-engineer-roadmap/README.md) is the canonical
  long-term software-engineering and career plan, maintained in this repository.

The AIML files here are sequencing and coverage checklists. When a topic appears
both here and in a detailed curriculum, the detailed curriculum is the source
of truth.

## Learning Tracks

### [MATH-Routine — 6-phase mathematics master program](MATH-Routine/README.md)

**Current mathematics study commitment:** 3 hours/day × 7 days = **21 hours/week**, planned as **6 phases (0–5), 312 weeks and 6,552 scheduled hours**. [Phase 0](MATH-Routine/Phase-0/README.md) is fully built first; Phase 1 begins after its mastery gate. This is a **separate mathematics-focused program** from the older MAANG combined routine, which budgets mathematics at 5–7 hours/week; schedules must be reconciled rather than added automatically.


### [MAANG Engineering & Mathematics](maang-engineer-roadmap/README.md)

A two-year software-engineering and mathematics roadmap with project milestones,
interview preparation, weekly routines, and monthly reviews.

### [Artificial Intelligence & Machine Learning](AIML/README.md)

A complete one-year AI/ML learning framework covering mathematics, Python, classical machine learning, deep learning, computer vision, NLP, large language models, reinforcement learning, generative AI, MLOps, research skills, projects, resources, and progress tracking.

## Repository Philosophy

Each learning track should follow the same cycle:

1. Learn the intuition.
2. Study the mathematics and theory.
3. Implement the idea from scratch.
4. Use the standard library or framework implementation.
5. Build a project.
6. Explain the concept in your own words.
7. Review and improve it over time.

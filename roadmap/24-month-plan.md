# 24-Month Plan

Each month has one primary engineering outcome. DSA, Codeforces, mathematics, and university continue throughout.

### Month 1: C++ refresh and complexity
- [ ] Syntax, functions, scope, references, pointers
- [ ] Arrays, strings, vectors, pairs
- [ ] Structs, classes, constructors
- [ ] Big-O time and space analysis
- [ ] STL: vector, stack, queue, deque, set, map
- [ ] Solve 20–25 easy C++ problems
- [ ] Create a reusable competitive-programming template

### Month 2: Core problem-solving patterns
- [ ] Sorting and custom comparators

- [ ] Two pointers and sliding window
- [ ] Binary search and binary search on answer
- [ ] Hashing and frequency counting

# Computer Vision

## Foundations

- Images as tensors, color spaces, normalization, resizing, interpolation, and augmentation
- Convolution, kernels, padding, stride, dilation, pooling, receptive fields, and feature maps
- Parameter counts, output-shape calculations, and computational cost
- Classification metrics, class imbalance, and visual error analysis

## Architectures

- LeNet, AlexNet, VGG, Inception concepts
- Residual networks and skip connections
- DenseNet, EfficientNet, and mobile architectures
- Transfer learning and fine-tuning strategies
- Vision transformers, patch embeddings, and self-attention
- Self-supervised and contrastive vision learning concepts

## Tasks

- Image classification and multilabel classification
- Object detection: R-CNN family, SSD, YOLO concepts, anchors, NMS, mAP
- Semantic, instance, and panoptic segmentation
- U-Net, fully convolutional networks, and Mask R-CNN concepts
- Keypoint estimation, OCR, metric learning, and image retrieval
- Vision-language tasks and image-text embeddings

## Practice

1. Implement a small convolution operation from scratch.
2. Train a transfer-learning classifier and inspect failure cases.
3. Build an object-detection pipeline.
4. Train a U-Net-style segmentation model.
5. Compare a CNN and a vision transformer on the same task.

## Projects

- Plant disease or waste classification
- Traffic-sign or retail-object detector
- Medical or satellite image segmentation
- Face verification or visual similarity search
- Image captioning or multimodal retrieval

## Mastery Checklist

- [ ] I can calculate convolution output shapes and parameter counts.
- [ ] I understand receptive fields and residual connections.
- [ ] I can choose among classification, detection, and segmentation.
- [ ] I can evaluate detection and segmentation correctly.
- [ ] I can fine-tune pretrained models without severe data leakage.
- [ ] I perform visual error analysis and test robustness to transformations.

# Advanced Projects and Capstones

Advanced work should combine research, system design, careful evaluation, and professional documentation. Complete one major capstone rather than several unfinished ideas.

## 1. Production RAG Platform

- Ingest multiple document formats with versioned parsing and metadata.
- Implement sparse, dense, and hybrid retrieval with reranking.
- Build a labeled evaluation set for retrieval and answers.
- Add citations, access controls, caching, observability, and fallback behavior.
- Compare quality, latency, and cost across models and configurations.

## 2. Domain-Specific Language Model Adaptation

- Define a narrow domain and measurable task.
- Curate and document a legally usable dataset.
- Compare prompting, retrieval, supervised fine-tuning, and parameter-efficient tuning.
- Evaluate factuality, calibration, robustness, latency, and memory.
- Produce a model card and reproducible training report.

## 3. Multimodal Assistant

- Combine image understanding, text retrieval, and structured tool use.
- Build task-specific evaluations rather than relying only on demonstrations.
- Test ambiguous inputs, missing context, and conflicting modalities.
- Include privacy controls and clear human-confirmation steps.

## 4. Research Paper Reproduction

- Reproduce a strong baseline and one central result from a paper.
- Match dataset, preprocessing, metrics, and compute as closely as practical.
- Run ablations and investigate discrepancies.
- Publish a report separating reproduced, partially reproduced, and unreproduced claims.

## 5. ML Platform or Training System

- Create reusable data validation, training, evaluation, registry, and deployment components.
- Add configuration, tests, CI, experiment tracking, and monitoring.
- Demonstrate the platform on at least two models or datasets.
- Document system architecture and trade-offs.

## 6. Computer Vision at the Edge

- Train a detection or segmentation model.
- Compress or quantize it for limited hardware.
- Compare accuracy, latency, memory, and power constraints.
- Build a live or recorded demonstration with robust failure handling.

## 7. Reinforcement-Learning Study

- Compare multiple algorithms under controlled seeds and budgets.
- Perform reward, exploration, and hyperparameter ablations.
- Report instability and negative results honestly.
- Include videos, learning curves, confidence intervals, and reproducible environments.

## 8. Trustworthy AI Evaluation Suite

- Build reusable tests for calibration, robustness, subgroup performance, distribution shift, and explanation stability.
- Apply the suite to several models.
- Document where metrics conflict and how deployment decisions should be made.

## Capstone Requirements

- [ ] Clearly scoped problem with real motivation
- [ ] Literature review and strong baselines
- [ ] Reproducible data and environment instructions
- [ ] Well-designed validation and evaluation
- [ ] Ablations or meaningful comparative experiments
- [ ] Error, robustness, and subgroup analysis
- [ ] Tested implementation
- [ ] Deployment or convincing system demonstration
- [ ] Architecture diagram
- [ ] Technical report
- [ ] Limitations, ethics, and responsible-use discussion
- [ ] Portfolio-quality README and presentation

## Suggested Final Deliverables

1. Public or private GitHub repository
2. Reproducible setup and commands
3. Technical report
4. Demo video or live application
5. Results table and experiment log
6. Architecture and data-flow diagrams
7. Five-minute non-technical explanation
8. Fifteen-minute technical presentation

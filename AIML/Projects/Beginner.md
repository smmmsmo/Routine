# Beginner Projects

These projects emphasize fundamentals, clean validation, and learning to finish small systems.

## 1. House Price Regression

- Compare mean baseline, linear regression, regularized regression, random forest, and gradient boosting.
- Practice missing-value handling, encoding, scaling, cross-validation, and residual analysis.
- Deliverable: reproducible training pipeline and error-analysis report.

## 2. Spam or Toxic-Message Classifier

- Compare bag-of-words/TF-IDF with logistic regression and Naive Bayes.
- Study precision-recall trade-offs and threshold selection.
- Deliverable: text preprocessing pipeline and simple inference interface.

## 3. Customer Segmentation

- Use scaling, PCA visualization, k-means, hierarchical clustering, and DBSCAN.
- Explain why clusters are or are not meaningful.
- Deliverable: segment profiles and limitations report.

## 4. Recommendation Baseline

- Build popularity, user-item, and content-similarity baselines.
- Use appropriate offline splits and ranking metrics.
- Deliverable: recommendation notebook and evaluation summary.

## 5. Image Classifier with Transfer Learning

- Fine-tune a pretrained CNN on a small, well-defined dataset.
- Add augmentation, confusion matrices, and visual error analysis.
- Deliverable: inference script or small web demo.

## 6. NumPy Neural Network

- Implement linear layers, activations, losses, backpropagation, and gradient checking.
- Deliverable: tested educational implementation and learning-curve plots.

## 7. Sentiment Analysis Comparison

- Compare TF-IDF, a small recurrent model, and a pretrained transformer.
- Deliverable: model comparison including accuracy, latency, and failure examples.

## 8. Tabular Data Explorer

- Create reusable code that reports schema, missingness, distributions, correlations, and suspicious values.
- Deliverable: command-line tool or notebook template with tests.

## Completion Standard

For at least three beginner projects:

- [ ] baseline and validation are correct;
- [ ] code runs from a clean environment;
- [ ] results include error analysis;
- [ ] README explains decisions and limitations;
- [ ] one project includes a usable demo.

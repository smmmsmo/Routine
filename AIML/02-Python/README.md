# Python for AI and Machine Learning

> This is a scheduling checklist, not a second Python curriculum. Follow the
> runnable lessons and exercises in
> [`MooLearning/python`](https://github.com/MooLearning/python); use this page
> only to confirm the Python capabilities needed by the AIML roadmap.

## Core Python

- Variables, control flow, comprehensions, functions, scope, modules, and packages
- Data structures, mutability, copying, hashing, and complexity basics
- Classes, dataclasses, inheritance, composition, and protocols
- Iterators, generators, decorators, context managers, and exceptions
- Type hints, documentation, logging, testing, profiling, and debugging
- Virtual environments, dependency management, configuration, and reproducibility

## Scientific Python

- NumPy arrays, dtypes, indexing, broadcasting, vectorization, random sampling, and linear algebra
- pandas Series/DataFrame operations, joins, groupby, reshaping, missing data, and time series
- Matplotlib for clear exploratory and explanatory plots
- SciPy for optimization, statistics, sparse matrices, and scientific routines
- SymPy for symbolic checking when useful

## ML Tooling

- Jupyter notebooks versus reusable Python modules
- scikit-learn estimators, transformers, pipelines, and model selection
- PyTorch tensors, datasets, models, training loops, and device management
- Git, Linux shell, environment variables, and command-line interfaces
- Unit tests, data validation, linting, and formatting

## Exercises

1. Reimplement common statistics with pure Python and NumPy.
2. Create an exploratory data-analysis notebook and a reusable preprocessing module.
3. Build a command-line training script with configuration and logging.
4. Add tests for preprocessing and metric functions.
5. Profile a slow loop and replace it with vectorized operations.

## Projects

- Dataset profiler and report generator
- Reusable ML experiment template
- CSV cleaning command-line tool
- NumPy neural-network primitives package

## Mastery Checklist

- [ ] I can structure code beyond a notebook.
- [ ] I understand array shapes, dtypes, broadcasting, and vectorization.
- [ ] I can write tests and debug data pipelines.
- [ ] I can create reproducible environments.
- [ ] I can move data and models between CPU and GPU safely.
- [ ] I can package a training/inference workflow cleanly.

# AI/ML Resources

Use resources selectively. The goal is not to finish every book and course; it is to use the smallest set that helps you understand, implement, and build.

## Recommended Core Path

1. **Mathematics:** *Mathematics for Machine Learning* plus MIT/3Blue1Brown material.
2. **Classical ML:** *An Introduction to Statistical Learning* and *Hands-On Machine Learning*.
3. **Deep Learning:** Dive into Deep Learning, PyTorch tutorials, and selected chapters from the Goodfellow text.
4. **Vision:** Stanford CS231n.
5. **NLP:** Stanford CS224N and the Hugging Face course.
6. **LLMs:** transformer papers, Stanford CS25-style lectures, and official framework documentation.
7. **RL:** David Silver's course and Sutton & Barto.
8. **Production:** Full Stack Deep Learning, Made With ML, and *Designing Machine Learning Systems*.

## Resource Selection Rule

For each subject, choose:

- one primary course;
- one primary book or set of notes;
- official library documentation;
- exercises or implementation tasks;
- one project.

Add secondary resources only when the primary explanation is insufficient.

## Note-Taking Template

For each resource:

- Main concepts
- Important equations
- Assumptions
- Implementation details
- Common mistakes
- Questions

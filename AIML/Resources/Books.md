# Books

## Start Here

1. **Mathematics for Machine Learning** — Marc Peter Deisenroth, A. Aldo Faisal, Cheng Soon Ong
2. **An Introduction to Statistical Learning** — James, Witten, Hastie, Tibshirani, and Taylor
3. **Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow** — Aurélien Géron
4. **Dive into Deep Learning** — Zhang, Lipton, Li, and Smola
5. **Designing Machine Learning Systems** — Chip Huyen

## Mathematics and Statistics

- **Convex Optimization** — Boyd and Vandenberghe

- **Machine Learning Design Patterns** — Lakshmanan, Robinson, and Munn
- **Reliable Machine Learning** — Chen, Liao, and Shi
- **The Craft of Research** — Booth, Colomb, Williams, Bizup, and Fitzgerald

## Reading Strategy

- Do not read every book cover to cover.
- Read the chapter that supports the current roadmap topic.
- Solve exercises and implement ideas while reading.
- Keep one primary text per subject and use others as references.
- Revisit difficult chapters after gaining implementation experience.

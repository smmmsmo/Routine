# Foundational Paper Reading List

Read papers when the corresponding topic appears in the roadmap. Start with the abstract, figures, and conclusion; then return for equations and experiments.

## Classical Machine Learning and Representation

- *A Few Useful Things to Know About Machine Learning* — Pedro Domingos
- *Random Forests* — Leo Breiman
- *Greedy Function Approximation: A Gradient Boosting Machine* — Jerome Friedman
- *A Tutorial on Support Vector Machines for Pattern Recognition* — Christopher Burges
- *Stochastic Neighbor Embedding* and later t-SNE work

## Deep Learning

- *Learning Representations by Back-Propagating Errors*
- *ImageNet Classification with Deep Convolutional Neural Networks* — AlexNet
- *Deep Residual Learning for Image Recognition* — ResNet
- *Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift*
- *Adam: A Method for Stochastic Optimization*
- *Dropout: A Simple Way to Prevent Neural Networks from Overfitting*

## NLP and Transformers

- *Efficient Estimation of Word Representations in Vector Space* — Word2Vec
- *Sequence to Sequence Learning with Neural Networks*
- *Neural Machine Translation by Jointly Learning to Align and Translate*
- *Attention Is All You Need*
- *BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding*
- *Language Models are Few-Shot Learners*

## LLM Adaptation and Retrieval

- *Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks*
- *LoRA: Low-Rank Adaptation of Large Language Models*
- *QLoRA: Efficient Finetuning of Quantized LLMs*
- *Training Language Models to Follow Instructions with Human Feedback*
- *Direct Preference Optimization: Your Language Model is Secretly a Reward Model*

## Computer Vision and Multimodal Learning

- *An Image is Worth 16x16 Words* — Vision Transformer
- *Learning Transferable Visual Models From Natural Language Supervision* — CLIP
- *U-Net: Convolutional Networks for Biomedical Image Segmentation*
- *Faster R-CNN: Towards Real-Time Object Detection with Region Proposal Networks*
- Selected YOLO-family papers, comparing architectural and evaluation changes

## Generative Models

- *Auto-Encoding Variational Bayes*
- *Generative Adversarial Nets*
- *Denoising Diffusion Probabilistic Models*
- *High-Resolution Image Synthesis with Latent Diffusion Models*

## Reinforcement Learning

- *Playing Atari with Deep Reinforcement Learning*
- *Human-level Control through Deep Reinforcement Learning*
- *Policy Gradient Methods for Reinforcement Learning with Function Approximation*
- *Proximal Policy Optimization Algorithms*

## Reading Record

For each paper, record:

1. Problem and motivation
2. Main contribution
3. Method and important equations
4. Data, baselines, and metrics
5. Strongest evidence
6. Weaknesses and assumptions
7. Reproduction idea
8. Follow-up questions

## Minimum Yearly Target

- 8 foundational papers
- 8 papers in the chosen specialization
- 4 recent or contrasting papers
- 1 reproduction or partial reproduction

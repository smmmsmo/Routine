# Artificial Intelligence & Machine Learning

This directory is a one-year, project-driven roadmap for developing a strong understanding of artificial intelligence and machine learning—from mathematics and classical algorithms to deep learning, LLMs, deployment, and research.

## One-Year Target

By the end of the year, you should be able to:

- Explain the mathematical foundations of major ML methods.
- Implement core algorithms from scratch using NumPy.
- Build reliable ML systems with scikit-learn and PyTorch.
- Work with tabular data, images, text, audio, and multimodal data.
- Understand neural networks, CNNs, sequence models, attention, and transformers.
- Fine-tune and evaluate pretrained models and small language models.
- Build retrieval-augmented generation and tool-using AI applications.
- Package, deploy, monitor, and improve models in production.
- Read research papers and reproduce selected results.
- Present a credible portfolio of end-to-end AI projects.

## Core Learning Loop

For every important topic:

1. **Understand:** learn the intuition and vocabulary.
2. **Derive:** work through the mathematics by hand.
3. **Implement:** code a minimal version from scratch.
4. **Apply:** use a standard library on a real dataset.
5. **Evaluate:** choose metrics, analyze errors, and check leakage.
6. **Explain:** write a concise note or teach the concept.
7. **Build:** integrate it into a small project.

## Weekly Time Budget

A strong target is **15–20 hours per week**:

- 4–5 hours: mathematics and theory
- 6–8 hours: coding and implementation
- 2–3 hours: courses, books, and notes
- 2–3 hours: projects and experiments
- 1–2 hours: research papers and review

## Evidence of Mastery

Do not mark a topic complete merely because a video ended. A topic is complete when you can:

- explain it without notes;
- derive or justify the main equations;
- implement a simplified version;
- identify its assumptions and failure modes;
- select suitable metrics;
- compare it with alternatives;
- use it in a project and document the results.

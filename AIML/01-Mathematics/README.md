# Mathematics for Machine Learning

Mathematics is the language used to describe models, optimization, uncertainty, and generalization. The goal is not abstract completeness; it is enough depth to derive, implement, diagnose, and compare ML methods.

## Study Order

1. [Linear Algebra](Linear-Algebra.md)
2. [Calculus](Calculus.md)
3. [Probability](Probability.md)
4. [Statistics](Statistics.md)
5. [Optimization](Optimization.md)

## Shared Practice Rules

- Work calculations by hand before using software.
- Translate equations into NumPy code.
- Visualize geometric or probabilistic ideas.
- Keep a formula sheet, but also record assumptions and interpretations.
- For every major formula, answer: what are the shapes, units, assumptions, and failure cases?

## Minimum Mathematical Toolkit

- Functions, logarithms, exponentials, summation notation, and basic proofs
- Vector and matrix operations
- Derivatives and gradients
- Probability distributions and conditional probability
- Estimation, uncertainty, and hypothesis testing
- Numerical optimization and regularization

# Statistics

## Topics

- Populations, samples, parameters, statistics, and sampling bias
- Mean, median, quantiles, variance, covariance, and robust summaries
- Sampling distributions and standard errors
- Point estimation and estimator properties: bias, variance, consistency, and efficiency
- Confidence intervals and bootstrap methods
- Hypothesis testing, p-values, power, Type I and Type II errors
- Maximum likelihood estimation and maximum a posteriori estimation
- Bayesian inference, priors, likelihoods, and posteriors
- Correlation versus causation
- Experimental design, randomized trials, confounding, and A/B testing
- Multiple comparisons and false discovery
- Calibration, uncertainty, and statistical reporting

## ML Connections

- Estimating model performance
- Cross-validation uncertainty
- Bias-variance trade-off
- Feature selection and experimentation
- Maximum-likelihood loss functions
- Reliable comparison of models

## Practice

- Bootstrap a confidence interval
- Run and interpret a hypothesis test
- Derive MLEs for simple distributions
- Simulate Type I/II errors and statistical power
- Compare models using repeated cross-validation

## Mastery Checklist

- [ ] I can distinguish a population parameter from a sample statistic.
- [ ] I can explain confidence intervals correctly.
- [ ] I understand what a p-value does and does not mean.
- [ ] I can derive simple maximum-likelihood estimators.
- [ ] I can identify confounding and sampling bias.
- [ ] I can report uncertainty instead of only point estimates.

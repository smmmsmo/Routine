# Linear Algebra

## Topics

- Scalars, vectors, matrices, tensors, shapes, and indexing
- Vector addition, scalar multiplication, dot products, angles, cosine similarity, and norms
- Matrix multiplication as linear transformation and composition
- Transpose, inverse, identity, trace, determinant, rank, null space, and column space
- Linear independence, basis, span, orthogonality, projections, and least squares
- Systems of linear equations and numerical stability
- Eigenvalues, eigenvectors, eigendecomposition, positive-definite matrices
- Singular value decomposition, low-rank approximation, and pseudoinverse
- Covariance matrices and principal component analysis
- Matrix calculus basics used in regression and neural networks

## ML Connections

- Data points and parameters as vectors
- Embeddings and similarity search
- Linear regression and least squares
- PCA and compression
- Attention matrix operations
- Convolutions represented as linear operators
- Low-rank adaptation and matrix factorization

## Practice

- Implement dot products, norms, projections, and cosine similarity with NumPy
- Solve a least-squares problem analytically and numerically
- Implement PCA using eigendecomposition and SVD
- Visualize a 2D linear transformation
- Compare full-rank and low-rank matrix approximations

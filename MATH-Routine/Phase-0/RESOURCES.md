# Phase 0 — Quality-first resource library

**Policy (updated 2026-10-28):** Select the strongest **fit for mastery, depth, clarity, problem quality and progression to university research**, **regardless of cost**. University library/eBook/print access is preferred. Free resources are welcome because they're excellent, *not* because they are free. This policy carries forward to Phases 1–5 when those are built.

**Study rule: ONE main spine book + ONE proof book, with targeted enrichment.** Do NOT attempt to finish every book listed. A rigorous but overwhelming resource stack would delay mastery.

All listed sources have been checked against university/publisher/author pages. **There is no single universally 'best' textbook for every learner:** Stewart is the best fit for your current *complete revision spine*; Lang and Gelfand deepen intuition; AoPS raises problem-solving difficulty; Velleman introduces disciplined proof writing.

## Verified no-cost alternatives (equally valid when effective)

- **OpenStax — Algebra and Trigonometry, 2e:** https://openstax.org/books/algebra-and-trigonometry-2e/pages/1-introduction-to-prerequisites. Thorough exercises and clear standard coverage.
- **OpenStax — Precalculus, 2e:** https://openstax.org/books/precalculus-2e/pages/1-introduction-to-functions. Standard comprehensive precalculus alternative.
- **Richard Hammack — Book of Proof (official free PDF):** https://richardhammack.github.io/BookOfProof/index.html. Excellent proof course; substitute for Velleman if it suits your learning better.
- **Khan Academy Trigonometry:** https://www.khanacademy.org/math/trigonometry. Good active drills for unit circle/identities.
- **3Blue1Brown Essence of Calculus:** https://www.3blue1brown.com/topics/calculus. Strong visual intuition; not an exercise course.

## What to actually read first

1. Borrow **Stewart–Redlin–Watson *Precalculus*** (8th edition preferred; 7th is acceptable if library access differs).
2. Borrow **Velleman's *How to Prove It***. Start with short logic/sets sections when time permits.
3. Use **Lang *Basic Mathematics*** *only* for forgotten/fuzzy topics you cannot explain after Stewart.
4. Open AoPS when comfortable with routine problems; don't let competition difficulty obstruct foundation repair.
5. For each week: solve ~35–55 thoughtfully chosen problems including mixed/review tasks, one derivation and 2–5 non-routine problems when suitable.

## Session method: read → solve → explain → recall

- Pre-read definitions and notation, derive a rule before memorizing.
- Work 3–5 examples and 5–10 *unseen* exercises in each significant section.
- Attempt without solutions for a meaningful period; log unsolved problems.
- Show justification, forbidden domains and geometric meaning where needed.
- Revisit 2, 7 and 21 days later without notes; use the [weekly schedule](WEEK-BY-WEEK.md) and [tracker](ROUTINE-AND-TRACKER.md).
- When ready, include challenge problems and proofs instead of indefinitely repeating easy drills.

## Access and selection

Ask the university library for eBooks/print; check legal institutional access first. Avoid unofficial pirated copies. Price doesn't determine quality; availability may vary by edition/license. **Do not purchase every optional book:** one great primary textbook mastered deeply beats eight textbooks skimmed.

## Future phase resource selection policy

When Phase 1 unlocks, select a similarly rigorous combination of established university texts, top lecture courses, well-designed exercise sets, and research-facing references; use free materials when they're genuinely strongest, and paid classics when those are better. The Phase 1–5 book list is intentionally NOT finalized now because we're completing Phase 0 first.

# Phase 0 — Complete syllabus and prerequisite checklist

> Mark a checkbox **only after** (1) a correct no-notes solution, (2) explaining why the method works, and (3) recalling a similar problem 7+ days later. Priority: **repair forgotten school math**, not race to university topics.

## P0-A. Numeric literacy and algebra (Weeks 1–4)

### A01 — Numbers and arithmetic
- [ ] Natural/whole/integers/rational/irrational/real numbers; ordering and number line.
- [ ] Sign rules, order of operations, absolute value, distance and intervals.
- [ ] Prime factors, divisibility, GCD/LCM and fraction simplification.
- [ ] Fraction arithmetic, mixed fractions, ratios, proportions and percentages.
- [ ] Decimals, repeating decimals, rounding, estimation, scientific notation.
- [ ] Units, rates, dimensional consistency and word-problem translation.

### A02 — Exponents, radicals and expressions
- [ ] Commutative/associative/distributive laws.
- [ ] Integer, negative, fractional and rational exponents.
- [ ] Root operations; radical rationalization; absolute-value subtleties.
- [ ] Expand, factor, simplify polynomial expressions.
- [ ] Notable identities: squares, cubes, difference of squares, sum/difference of cubes.
- [ ] Restrictions when simplifying rational expressions; cancelling only factors.

### A03 — Equations, inequalities and systems
- [ ] One-variable linear equations, rearranging formulas.
- [ ] Linear inequalities, interval/set notation, compound inequalities.
- [ ] Absolute-value equations/inequalities.
- [ ] Simultaneous linear equations by substitution/elimination.
- [ ] Quadratics by factoring, completing square, quadratic formula, discriminant.
- [ ] Polynomial roots and elementary remainder/factor theorems.
- [ ] Rational and radical equations; extraneous roots and domain checks.
- [ ] Sign charts; polynomial/rational inequalities.
- [ ] Elementary complex numbers i, a+bi, conjugation and operations (review level).

## P0-B. Functions, logarithms, trig and geometry (Weeks 5–9)

### B01 — Functions
- [ ] Relations versus functions, notation f(x), domain, codomain and range.
- [ ] Evaluate piecewise functions and test their domains.
- [ ] Intercepts, roots, sign, extrema, symmetry, monotonicity.
- [ ] Transformations: shift, scale, reflect; graph from formula.
- [ ] Composite and inverse functions; one-to-one; restriction for inverses.
- [ ] Linear, quadratic, cubic, polynomial and rational graph families.
- [ ] Horizontal/vertical asymptotes and end behavior.

### B02 — Exponential and logarithmic mastery
- [ ] Exponential growth/decay; a^x for a>0, a≠1; e^x.
- [ ] Logarithm as inverse of exponential; domain x>0.
- [ ] Log product, quotient and power laws derived from exponent rules.
- [ ] Change of base; natural log; common log.
- [ ] Solve exponential equations analytically and numerically.
- [ ] Solve logarithmic equations with domain checks and extraneous solutions.
- [ ] Log/exponential graph transformations and asymptotes.
- [ ] Applications: growth, doubling time, compound interest, pH/order-of-magnitude intuition.
- [ ] Why log(a+b) is NOT log(a)+log(b).

### B03 — Plane/coordinate geometry
- [ ] Angles, parallel lines, triangles, congruence/similarity, Pythagoras.
- [ ] Circle measurements, area/perimeter, surface area/volumes (review).
- [ ] Cartesian distance, midpoint, gradient/slope, line equations and intersections.
- [ ] Circles in coordinates, simple parabolas, introductory conics.
- [ ] Geometric and algebraic representations of the same problem.

### B04 — Trigonometry
- [ ] Degrees/radians conversion; arc length and angular measure.
- [ ] Right-triangle sin/cos/tan and reciprocals; quadrant signs.
- [ ] Unit circle at key angles: 0, π/6, π/4, π/3, π/2 and quadrantal angles.
- [ ] Sine/cosine/tangent graphs, domain, range, period, amplitude, phase shifts.
- [ ] Fundamental identities: sin²+cos²=1, tan=sin/cos, reciprocal identities.
- [ ] Even/odd and angle-sum/difference identities; double-angle identities.
- [ ] Simplify/prove basic trigonometric identities (no circular reasoning).
- [ ] Solve standard trig equations in intervals; general solution families.
- [ ] Inverse trig function principal-value domains/ranges.
- [ ] Sine rule, cosine rule, triangle area; applications to triangles.
- [ ] Coordinate geometry and trigonometry connections.

## P0-C. Precalculus and calculus readiness (Weeks 10–13)

### C01 — Sequences, vectors and modeling
- [ ] Arithmetic/geometric sequences, nth terms and finite geometric sums.
- [ ] Sigma notation, reading indexed expressions.
- [ ] Basic binomial coefficients and binomial expansion.
- [ ] 2D vectors, components, magnitude, direction, addition and dot product intuition.
- [ ] Parametric curve introduction; simple polar coordinate awareness.
- [ ] Model data with linear, exponential or quadratic functions; interpret units.

### C02 — Limits and continuity (readiness, not Analysis I)
- [ ] Intuitive behavior as x→a, left/right limits and infinity as direction of growth.
- [ ] Evaluate elementary limits using direct substitution and factoring.
- [ ] Handle 0/0 as an *indeterminate form* by simplifying where valid.
- [ ] One-sided/infinite limits and asymptotic behavior.
- [ ] Continuity at a point and on an interval; removable/jump/infinite discontinuities.
- [ ] Derivative as a limit of average rates (first-principles definition).
- [ ] Interpret difference quotient geometrically and numerically.

### C03 — Intro derivatives and integration intuition
- [ ] Power, product, quotient and chain rules (introductory use).
- [ ] Differentiate sin, cos, e^x and ln x (with domain caveats).
- [ ] Tangent line and instantaneous rate; local linear approximation.
- [ ] Critical points and very simple optimization.
- [ ] Antiderivative and area-under-curve intuition; Riemann sums as approximation.
- [ ] Explain what derivative/integral study will deepen in Phase 1.

## P0-D. Mathematical reasoning and programming (Weeks 1–16, final focus 14–16)

### D01 — Proof literacy
- [ ] Distinguish example from proof, conjecture from theorem.
- [ ] Set notation, union/intersection/complement, subset and membership.
- [ ] Statements, negation, and/or, implication and quantifiers.
- [ ] Direct proof and counterexample, simple contrapositive/contradiction.
- [ ] Write induction base case, hypothesis and inductive step on simple sums.
- [ ] Identify logical gaps and unstated assumptions in a purported proof.

### D02 — Mathematical programming and verification
- [ ] Python functions, loops, list comprehensions; numeric types and floating point.
- [ ] Plot polynomial/log/trig functions with valid domains.
- [ ] Compare analytical and finite-difference derivative estimates.
- [ ] Use NumPy arrays or pure Python to compute simple sequences.
- [ ] Use SymPy to *check* an answer only after independently solving.
- [ ] Write a clear README describing assumptions, tests, outputs and limitations.

## Exit gate (not calendar-based)

- [ ] Fresh comprehensive Phase 0 examination ≥80/100.
- [ ] No algebra, exponential/logarithm, trig or function category <70%.
- [ ] Correctly justify 2–3 elementary proofs or derivations in complete sentences.
- [ ] Re-solve 10 representative problems 7 days after learning them with ≥80% accuracy.
- [ ] Complete and explain one verified graphing/numerical project.
- [ ] Record outstanding weaknesses and schedule a repair loop before Phase 1.

## Rule for weak subtopics
Red (can't solve) → 2 worked examples → 8 guided and 8 independent problems → 2 mixed problems → re-test in 2, 7 and 21 days. Yellow (slow/errors) → 6 independent + 2 mixed + 7-day test. Green → spaced review only.

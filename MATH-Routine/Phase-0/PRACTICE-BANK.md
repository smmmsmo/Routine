# Phase 0 — 60 original mixed practice problems

Use this as a **supplement** to textbook sections, not the sole supply of 35–55 weekly attempts. Solve without notes, write steps, and record difficulties in the error log. Each set can be revisited with altered values after 2/7/21 days. Don't open the answers until a real attempt.

## Set 1: Number sense

1. Compute exactly: 5/12 + 7/18.
2. Convert 0.375 to a reduced fraction.
3. Calculate 25% of 160.
4. Find gcd(84,126).
5. Evaluate |-7| - |3-8|.
6. Simplify (2.4×10^3)/(6×10^-2).

## Set 2: Exponents and algebraic expressions

7. Expand (x+2)(x-3).
8. Simplify (a²-b²)/(a-b), stating restrictions.
9. Evaluate 16^(3/4).
10. Simplify (x³ y^-2)/(x^-1 y); state nonzero conditions.
11. Simplify sqrt(50).
12. Factor x³-8.

## Set 3: Equations and inequalities

13. Solve 5x-8=2x+7.
14. Solve 3-2x>=9.
15. Solve |x+1|=4.
16. Solve x+y=7 and x-y=1.
17. Solve 1/(x-1)=1/2.
18. Solve sqrt(x+1)=x-1, rejecting invalid roots.

## Set 4: Quadratics and polynomials

19. Solve x²-6x+8=0.
20. Find vertex of y=x²+4x+1.
21. Compute discriminant of 2x²-4x+5; count real roots.
22. Factor 3x²+2x-1.
23. Find remainder when x³+2x+1 is divided by x-2.
24. Solve x²<=9.

## Set 5: Functions and graphs

25. Domain of sqrt(2x-6).
26. If f(x)=x²-2, evaluate f(-3).
27. Find inverse of g(x)=2x+1.
28. Find vertex of h(x)=(x+4)²-5.
29. For f(x)=x+2 and g(x)=x², calculate f(g(3)).
30. Locate undefined input / vertical asymptote of y=(x+1)/(x-5).

## Set 6: Logarithms and exponentials

31. Evaluate log_5(125).
32. Solve log_2(x)=4.
33. Evaluate log_10(1000).
34. Simplify ln(e³).
35. Simplify log_3(9)+log_3(3).
36. Solve 4^x=1/16.

## Set 7: Unit circle and trig values

37. Evaluate sin(pi/3).
38. Evaluate cos(pi/4).
39. Evaluate tan(pi/6).
40. Evaluate sin(7pi/6).
41. Evaluate cos(3pi/2).
42. Convert 225° to radians.

## Set 8: Trig reasoning and geometry

43. Explain sin²(theta)+cos²(theta)=1 using unit-circle geometry.
44. Simplify 1-cos²(theta).
45. Solve cos(x)=0 for 0<=x<2pi.
46. State the double-angle identity for sin(2theta).
47. Find hypotenuse of a right triangle with legs 6 and 8.
48. Convert 2pi radians to degrees.

## Set 9: Sequences, vectors and models

49. Find nth term of 3,7,11,... (first term n=1).
50. Find next term of 2,6,18,...
51. Find 1+2+...+20.
52. Magnitude of vector (3,4).
53. Compute (1,2) dot (3,-1).
54. Find future amount of 100 after two 10% growth periods.

## Set 10: Limits, derivative readiness and proofs

55. Evaluate lim_(x→1) (x²-1)/(x-1).
56. Differentiate x^4.
57. Differentiate sin(x).
58. Forward difference of f(x)=x² at x=1, h=0.1.
59. Give a direct proof that the sum of two even integers is even.
60. Provide a counterexample to 'all prime numbers are odd'.

# Phase 2 — Best-fit university resources (paid or free)

**Selection principle:** choose for mathematical rigor, clarity, proofs, problem sets and fit to a **72-week advanced-undergraduate syllabus**, regardless of price. University library access is encouraged. This is a **curated selection**, not a ranking of one universally 'best' book; do not read all listed books cover to cover.

## Carefully chosen secondary gateways (read only where referenced)

- **Topological vocabulary:** Munkres, *Topology*, introductory definitions and elementary examples **in Weeks 9–12 only**. Full general topology is a separate future elective.
- **Number theory:** Burton, *Elementary Number Theory*, divisibility, congruences, elementary theorems and Diophantine problems **Weeks 19–23**. No analytic/algebraic number theory in this block.
- **Fourier analysis:** MIT 18.03SC Fourier series materials and MIT 18.330 Fourier/sampling lectures in **Weeks 43–45**. Full harmonic analysis is a later specialization.
- **Analysis stretch:** Rudin is deliberately *optional*. Abbott provides a gentler entry while retaining proofs; choose Rudin for harder problems if ready.

## Why this set qualifies

- MIT 18.100B (2025) is a proof-based undergraduate analysis course with lecture videos, notes, problem sets and exams.
- MIT 18.03SC explicitly supplies notes, recitations, problem sets and exams for independent study.
- Harvard Stat 110 publishes its course and textbook links, including a 2nd-edition probability text.
- Stanford hosts the full Boyd–Vandenberghe convex optimization text with permission from Cambridge University Press.
- MIT 6.046J is a second-level course **requiring** introductory algorithms and discrete math; use it only after Phase 1 prerequisites.

These are strong institutional/author sources, and university-licensed paid textbooks are equally legitimate.

## Study load and what *not* to do

Each week's **21 hours already includes** textbook reading, exercises, proofs, implementation where needed, and a 3-hour review/test day. Use the main book as the spine and an optional source only where the main text is unclear or too easy. **Do not take full courses from every book in parallel**: the 72-week timetable would no longer add up.

# MATH-Routine — Math Foundations to Research

**Status: Phase 0 ACTIVE. Phases 1–5 are planned, not unlocked.**

This is the mathematics-only 21-hour/week program. It is separate from the older 5–7-hour MAANG/engineering combined routine in this repository. Do not add 21 math hours on top of an existing 19–23-hour schedule without explicitly reallocating other activities.

## Non-negotiable commitment

- **3 hours/day, 7 days/week = 21 scheduled hours/week**.
- **52 weeks/year = 1,092 scheduled hours/year**.
- The six-phase *planning model* uses 312 weeks / **6,552 scheduled hours** (~6 years). Real calendar duration will grow with rest, exams and prerequisite repairs; this is not a research-mastery guarantee.
- Progress only when the exit gate is passed. Week counts are budgets, not forced deadlines.
- Restart with an assessment and targeted review for previously learned but forgotten algebra, logarithms and trigonometry.

## Advancement policy

1. Diagnostic → study → independent problem solving → proof/explanation → spaced recall → exit exam.
2. **Target ≥80/100** on a fresh, mixed assessment, with no critical algebra/log/trig weakness and a completed mini-project. Re-test weak categories after repair.
3. Every fourth week emphasizes consolidation; week 16 is a formal Phase 0 gate.
4. If Phase 0 needs 20–24 weeks instead of 16, take the time. Do **not** start Phase 1 because a calendar page turned.
5. Phase 1 will be built *after* Phase 0 is passed; this repository intentionally does not pretend later phases are already fully designed.

## Study tracks

- **A — Core/pure mathematics** (definitions, calculations, proofs).
- **B — AI/ML mathematics** (gradients, linear algebra, probability, optimization; progressively).
- **C — CS mathematics** (logic, combinatorics, graphs, complexity).
- **D — Research skills** (proof notebooks, mathematical questions, paper reading later).

The tracks are interwoven according to prerequisites. During Phase 0, most time goes to foundations rather than advanced topics.
